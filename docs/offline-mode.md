# Hors ligne

Ouvrir la version construite en ligne, attendre Service Worker prêt, importer les données de transport et vérifier leur validité. Puis couper la connexion et recharger. La recherche, les calculs GTFS, comparaison, favoris, sources installées et exports locaux restent disponibles. Sans données importées, le calcul est désactivé.

Le fond OSM nécessite Internet ; il est activé par défaut (désactivable dans Paramètres) et ne reçoit aucun cache applicatif. En hors ligne les vecteurs locaux sont rendus sur une grille neutre. Aucun téléchargement massif de tuiles. Un fond hors ligne importable reste une évolution future.

Le navigateur peut supprimer les données (quota, mode privé, effacement manuel, éviction). Demander la persistance réduit ce risque sans garantie. La couverture complète de l’Île-de-France n’est pas revendiquée : préparer des sous-réseaux ou faire évoluer les index pour un flux complet.
