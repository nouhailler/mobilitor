# Import local

Formats : CSV UTF-8 (séparateur détecté par PapaParse, guillemets et BOM), GeoJSON FeatureCollection WGS84, ZIP GTFS. CSV de stations : `id,name,latitude,longitude`. Les GeoJSON Point deviennent des stations, LineString/MultiLineString des tracés, Polygon/MultiPolygon des limites. Propriétés de nom : name, nom, nom_gares, l_ar. Identifiant : id ou Feature.id ; à défaut index stable dans ce fichier. Géométries Lambert-93 à convertir avant import. GeometryCollection refusée. Pas de détection de doublons géographiques entre fichiers distincts.

GTFS : agency, stops, routes, trips, stop_times et calendar ou calendar_dates. Les heures explicites, références et séquences sont vérifiées. Les identifiants textuels sont conservés et préfixés côté base par le jeu de données. Les stops doivent avoir des coordonnées dans le profil accepté. Un hash SHA-256 détecte une version identique déjà installée. Un nouvel UUID distingue les versions différentes. Les shapes sont stockées mais pas tracées. Certains fichiers optionnels sont ignorés ; capacités non supportées affectant directement les horaires refusées (fréquences, pathways, montée à la demande, transferts spécifiques).

La taille compressée est limitée à 40 Mo ; tailles déclarées ZIP plafonnées à 250 Mo avant décompression. Il ne s’agit pas d’un sandbox hostile : n’importer que des fichiers de confiance. 500 000 horaires maximum. L’espace libre estimé doit couvrir 12 fois le fichier. La limite protège le téléphone mais ne garantit pas l’absence d’épuisement mémoire.

Validation complète avant écriture, transaction atomique, lots de 2 000, remplacement dans cette même transaction. Échec de quota : transaction annulée. Annulation : Worker terminé ; une transaction peut avoir terminé juste avant l’annulation, consulter la liste des jeux. Rapports visibles dans l’interface ; importJobs conserve les états. Pas de téléchargement direct : CORS et ressources actuelles ne sont pas vérifiés pour un accès depuis cette PWA. Les liens officiels servent à l’import manuel.
